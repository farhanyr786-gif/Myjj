## 🔥 **Ye kya cheez hai?**

> **HingScript** ek programming language hai jo **Hinglish** (Hindi + English) mein likhi jaati hai. Ismein wohi sab kuch kar sakte ho jo **Python** mein karte ho — functions, loops, classes, arrays, objects — sab kuch! Bas keywords Hinglish mein hain!

**Socho:** Python seekhna mushkil lagta hai? **HingScript seekho!** 🎯

chhapa("Namaste Duniya!")

ye x = 10
agar (x > 5) {
  chhapa("Bada hai!")
} wara {
  chhapa("Chhota hai!")

kaam factorial(n) {
  agar (n <= 1) {
    wapas 1

  wapas n * factorial(n - 1)
}

liye (i = 0; i < 5; i++) {
  chhapa(i)
}

banayo Student(naam) {
  ye.naam = naam
}

## 💻 **Live Code Examples**

### 1️⃣ **Hello Duniya** — Sabse pehla program 👋

```hingscript
# Namaste Duniya! HingScript mein pehla program
chhapa("Namaste Duniya! 🙏")
chhapa("HingScript chal raha hai!")

# Variable banao
ye naam = "HingScript Programmer"
ye umar = 25

chhapa("Mera naam: " + naam)
chhapa("Meri umar: " + sankhya(umar))
```

**Output:**
```
Namaste Duniya! 🙏
HingScript chal raha hai!
Mera naam: HingScript Programmer
Meri umar: 25
```

---

### 2️⃣ **Calculator** — Saare ganit ke kaam 🧮

```hingscript
ye a = 15
ye b = 4

chhapa("--- Calculator ---")
chhapa("Jod (a + b): " + sankhya(a + b))
chhapa("Ghatao (a - b): " + sankhya(a - b))
chhapa("Gunna (a * b): " + sankhya(a * b))
chhapa("Bhag (a / b): " + sankhya(a / b))
chhapa("Shesh (a % b): " + sankhya(a % b))

# Factorial function
kaam factorial(n) {
  agar (n <= 1) { wapas 1 }
  wapas n * factorial(n - 1)
}

chhapa("5 factorial = " + sankhya(factorial(5)))
```

---

### 3️⃣ **Classes** — Object Oriented HingScript! 🏗️

```hingscript
banayo Student(naam, marks) {
  ye.naam = naam
  ye.marks = marks
}

kaam marks_grade() {
  agar (ye.marks >= 90) { wapas "A+" }
  agar (ye.marks >= 80) { wapas "A" }
  agar (ye.marks >= 70) { wapas "B" }
  wapas "C"
}

ye student1 = new Student("Rahul", 92)
chhapa("Student: " + student1.naam)
chhapa("Grade: " + student1.marks_grade())
```

### 4️⃣ **Star Patterns** — Creative coding ⭐

```hingscript
# Star Triangle banao!
ye n = 5
liye (i = 1; i <= n; i++) {
  ye stars = ""
  liye (j = 0; j < i; j++) {
    stars = stars + "⭐"
  }
  chhapa(stars)
}
```

**Output:**
```
⭐
⭐⭐
⭐⭐⭐
⭐⭐⭐⭐
⭐⭐⭐⭐⭐
```

## 🧪 **How It Works — Engine Ka Magic**

```
📝 HingScript Code        chhapa("Namaste!")
        │
        ▼
┌─────────────────┐
│   🔤 LEXER      │  → Tokens mein todta hai
│   (lexer.ts)    │    [CHHAPA, LPAREN, STRING, RPAREN]
└─────────────────┘
        │
        ▼
┌─────────────────┐
│   🌳 PARSER     │  → AST (Abstract Syntax Tree) banata hai
│   (parser.ts)   │    { type: "PrintStatement", args: [...] }
└─────────────────┘
        │
        ▼
┌─────────────────┐
│   ⚡ INTERPRETER │  → Code execute karta hai
│ (interpreter.ts)│    → Output: "Namaste!"
└─────────────────┘
        │
        ▼
🖥️ Screen pe output dikhta hai!
```
